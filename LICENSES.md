# Licensing and attribution

This repository aggregates skill files from multiple sources. **There is no single license for the entire collection.** Follow the license and attribution requirements of each source and skill.

- Seeed skills are copied from `Seeed-Projects/Seeed-Jetson-DevelopTool`; consult that project’s MIT license.
- NVIDIA BSP and device skill snapshots are kept under their original directories with their upstream `LICENSE` files. NVIDIA describes these as CC-BY-4.0 for documentation and Apache-2.0 for source code.
- Machine-local Codex skills keep their original content and any notices included in the skill. `sources/sources.json` records their local paths and provenance; check an original upstream source before redistribution when no license is stated.
